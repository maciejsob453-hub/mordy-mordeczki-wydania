# Mordy Mordeczki — dwie gry, jedna biblioteka

[Pobierz launcher 3.0.2](https://github.com/maciejsob453-hub/mordy-mordeczki-wydania/releases/download/launcher-v3.0.2/Mordy.Mordeczki.Launcher-1bc9d1a69151.exe) i wybierz część, którą chcesz uruchomić.

- **Mordy Mordeczki — Sejm 1.1.217**: oryginalna gra z naprawionym Discord Rich Presence.
- **Mordy Mordeczki 2 — 1.0.2**: osobna gra z nowym silnikiem, kampanią, koalicjami z obietnicami i własnymi zakończeniami.

Obie części automatycznie pokazują aktywność w aplikacji Discord: menu, partię i etap rozgrywki. Dwójka dodaje grafikę gry, herb partii, kadencję i mandaty. Po późniejszym uruchomieniu Discorda połączenie jest ponawiane. Gracze nie wpisują ID ani tokenów; wymagane jest włączone udostępnianie aktywności w Discordzie. Aktualizacje obu gier pobiera obecny launcher 3.0.2.

Launcher rozpoznaje istniejącą jedynkę. Nowe instalacje umieszcza w oddzielnych folderach `Gry/MordyMordeczki1` i `Gry/MordyMordeczki2`. Obie części zachowują osobne zapisy.

Dotychczasowy launcher otrzymuje aktualizację przez swój dotychczasowy mechanizm. Jeżeli po aktualizacji otworzy jeszcze jedynkę, ponownie otwórz launcher, aby zobaczyć nową bibliotekę.

Windows 10/11, Microsoft Edge WebView2 Runtime. Gotowe aplikacje zawierają potrzebne biblioteki; Python nie wymaga osobnej instalacji. Pobrane gry działają offline.
