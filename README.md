# Mordy Mordeczki — dwie gry, jedna biblioteka

[Pobierz launcher 3.0.0](https://github.com/maciejsob453-hub/mordy-mordeczki-wydania/releases/download/launcher-v3.0.0/Mordy.Mordeczki.Launcher-6f4809398dba.exe) i wybierz część, którą chcesz uruchomić.

- **Mordy Mordeczki — Sejm 1.1.216**: oryginalna gra.
- **Mordy Mordeczki 2 — 1.0.0**: osobna gra z nowym silnikiem, kampanią, koalicjami z obietnicami i własnymi zakończeniami.

Launcher rozpoznaje istniejącą jedynkę. Nowe instalacje umieszcza w oddzielnych folderach `Gry/MordyMordeczki1` i `Gry/MordyMordeczki2`. Obie części zachowują osobne zapisy.

Dotychczasowy launcher otrzymuje aktualizację przez swój dotychczasowy mechanizm. Jeżeli po aktualizacji otworzy jeszcze jedynkę, ponownie otwórz launcher, aby zobaczyć nową bibliotekę.

Windows 10/11, Microsoft Edge WebView2 Runtime. Gotowe aplikacje zawierają potrzebne biblioteki; Python nie wymaga osobnej instalacji. Pobrane gry działają offline.
